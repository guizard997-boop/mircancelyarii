# Мир канцелярии — kawaii-тема и студийные фото

Архив адаптирован к текущей структуре Flask/Jinja магазина: существующие маршруты, страницы, админка и база данных сохраняются.

## В составе

- `apply_ui.py` — идемпотентно подключает розовую тему, быстрый AJAX-добавитель товара в предзаказ и seed-загрузчик; перед первым изменением `app.py` создаёт локальную копию `app.py.bak`.
- `ui_kawaii.py` — исходный вариант kawaii-компонентов из архива.
- `catalog_seed.py` — добавляет товары из `catalog/catalog.csv` при старте приложения; уже импортированные товары не дублируются.
- `tools/studio.py` — обрабатывает фотографии и сохраняет готовые изображения и CSV в `catalog/`.

## Проверка и запуск

Из корня репозитория выполните:

```sh
python apply_ui.py
python -m py_compile app.py catalog_seed.py apply_ui.py tools/studio.py
python app.py
```

Для локальной обработки фото установите дополнительные пакеты:

```sh
pip install pillow numpy opencv-python-headless "rembg[cpu]"
```

Положите исходные фото в `photos_raw/`, выполните `python tools/studio.py photos_raw catalog` (для белого фона добавьте `--bg white`), затем заполните `name`, `price` и `category` в `catalog/catalog.csv`. Пустое имя пропускается, пустая цена трактуется как «Цена по запросу». Повторная обработка сохраняет уже заполненные названия и цены.

`catalog/` является частью репозитория, поэтому добавленные изображения и CSV попадут на хостинг вместе с кодом. Не помещайте в неё приватные или неразрешённые к публикации файлы.

## Важно перед публикацией

В текущей публичной версии `app.py` уже присутствуют захардкоженные секретные значения. Их следует отозвать/сменить и перенести в переменные окружения хостинга до публикации; не добавляйте новые секреты в Git. Push в ветку `main` может автоматически запустить деплой Railway.
