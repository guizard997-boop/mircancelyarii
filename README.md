# Бесплатный AI через Hugging Face

## Токен
1. https://huggingface.co/settings/tokens
2. Create new token (Read достаточно)
3. Railway Variables:
   HF_TOKEN = hf_ваш_токен

## Как работает
Фото → Hugging Face BLIP (бесплатно) → название + категория → вы пишете цену

## Запасные варианты
- GEMINI_API_KEY — если HF не сработал
- Без ключей — название вручную
