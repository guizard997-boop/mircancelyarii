# Мир канцелярии: полный проект

Тёмный чёрно-белый сайт предзаказов в стиле Хэллоуина, без эмодзи. Flask + SQLite.

Хэллоуинские элементы (всё нарисовано SVG, лежит в `templates_data.py`): бегущая строка, стекающие капли, пауки на нитях, летающие мыши, луна с мёртвым деревом, привидения, тыквы, кладбище в подвале, мигающие глаза, свечи на входе в админку, страница ошибки с черепом. Часть элементов кликабельна. В админке декор отключён, чтобы не мешал работе.
Чтобы убрать что-то лишнее, удалите нужный блок в `base.html`: `sky` (летучие мыши), `deco` (строка, капли, пауки), `yard` (кладбище).

## Файлы
- `app.py` — сайт, админка, Telegram-бот
- `templates_data.py` — весь дизайн (CSS, шаблоны)
- `catalog_seed.py` — автозагрузка студийных фото из `catalog/`
- `tools/studio.py` — превращает фото товаров в студийные
- `requirements.txt`, `Procfile`, `.env.example`

## Запуск у себя
    pip install -r requirements.txt
    ADMIN_PASSWORD=секрет python app.py        # http://localhost:5000
Вход в админку: `/admin` (ссылки на неё на сайте нет).

## Деплой на Railway
1. Замените файлы в репозитории файлами из архива и сделайте `git push`.
2. Railway → Variables: добавьте `ADMIN_PASSWORD`, `SECRET_KEY`, `SITE_URL` (см. `.env.example`).
3. Чтобы база и загруженные фото не пропадали при перезапуске: Railway → ваш сервис → Volumes → создать том с путём `/data`, затем переменная `DATA_DIR=/data`.

## Реквизиты для оплаты
Админка → «Оплата». Можно добавить любое число способов (Оптима, Элсом, MBank, карта и т.д.): название, текст реквизитов, QR-код. Их можно менять, скрывать и удалять. Клиент видит их при оформлении и на странице «Предзаказ принят», с кнопкой «Копировать».
Реквизиты из старой версии сайта переносятся автоматически один раз.

## Студийные фото
    pip install pillow numpy opencv-python-headless "rembg[cpu]"
    python tools/studio.py photos_raw catalog          # тёмный фон (--bg soft или white для светлого)
Откройте `catalog/catalog.csv` (столбцы `file`, `name`, `description`, `price`, `category`) и закоммитьте папку `catalog/`. При запуске сайт создаст отсутствующие по фото товары; уже существующие записи и их цены не перезаписываются.
На сайте фото в списке чёрно-белые, цвет возвращается при наведении и на странице товара.

## Telegram-бот (необязательно)
Задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_IDS` (если не знаете свой id, напишите боту, он ответит). Затем Админка → Контакты → «Подключить webhook».
Бот присылает уведомления о новых предзаказах и добавляет товары по фото.

## Безопасность
Старый токен бота был в открытом репозитории. Перевыпустите его: @BotFather → /revoke. В коде секретов больше нет, всё берётся из переменных окружения.
